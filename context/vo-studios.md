## 用法

- 收到「幫我 add VO Recording @ DoubleDouble」/「DoubleDouble 地址」→ 對 studio 名攞返上表完整地址，填落 Calendar event `location`。
- **DoubleDouble ≠ 最常用嗰個**——DoubleDouble 係 #2（荃灣 One MidTown），唔係出現次數最多嘅 #1（觀塘 鴻運工廠 7C）。唔好因為 #1 出現得多就 default 當佢係 DoubleDouble。
- 新 studio / 地址有變 → 由 Kary confirm 後更新呢份 file。
